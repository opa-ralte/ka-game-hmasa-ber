## for those who wanna touch up on this...  

### 1st: clone the repo 🐑  

```bash
git clone https://github.com/opa-ralte/ka-game-hmasa-ber.git
cd ka-game-hmasa-ber
```

### 2nd: create a damn virtual environment *probably should do this man* 🦟

```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3rd: install them -> dependencies  

```bash
pip install -r requirements.txt
```

### 4th: verify the installation *if you want*

```bash
python -c "import pygame; print(f'Pygame {pygame.__version__} installed successfully!')"
```

## and if you wanna run the game...

Run the game with:  

```bash
python main.py
```
